# 프라미스A 교습소 홈페이지

서울 송파구 초·중등 전문 영어 교습소 **프라미스A**의 홈페이지입니다.
교육청 학원·교습소 등록번호 제5600호 · 교습과목 영어

👉 **https://kels5845-stack.github.io/promise-a/**

## 이 저장소에 든 것

화면에 보이는 정적 파일만 들어 있습니다. HTML 11개와 CSS·JS·이미지입니다.
빌드 과정이 없어, 올린 파일이 그대로 서비스됩니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 홈 |
| `about.html` | 교습소 소개 |
| `curriculum.html` | 커리큘럼 · 교재 (루티 잉글리시) |
| `elementary.html` | 초등 영어 정규반 |
| `middle.html` | 중·고등 내신반 |
| `tuition.html` | 수강료 · 수업 시간 |
| `faq.html` | 자주 묻는 질문 |
| `contact.html` | 상담 신청 |
| `privacy.html` | 개인정보 처리방침 |
| `landing.html` | 광고 유입용 랜딩 (검색 제외) |
| `404.html` | 없는 페이지 |

## 알아두실 것

- 페이지를 만드는 **생성 스크립트와 상담 자동화 서버 코드는 비공개 저장소**에 있습니다.
- 깃헙 페이지에는 서버가 없어 **알림톡 자동 발송은 여기서 동작하지 않습니다.**
- 내용을 고칠 때는 비공개 저장소에서 다시 만들어 이곳에 올립니다.
